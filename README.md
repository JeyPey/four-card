## На що зауважити в майбутньому:
*
 ```css
 margin-inline: auto;
 ```
Не обов'язково усюди піхати

```css
margin: 0 auto;

```
*
```css
.card__body > .subtitle {
  padding: 1px 0 0 1px;
  text-align: start;
  font-size: 13px;
}
```
Раніше в описі проекту я випадково назвав код `.card__body > .subtitle` вкладеністю. Мене виправили, і тепер я розібрався, як це називається правильно.

**У чому різниця:**
Конструкція з символом `>` — це насправді селектор із комбінатором дочірнього елемента. Він вибирає тільки ті елементи `.subtitle`, які лежать безпосередньо всередині `.card__body` на першому рівні (тобто є прямими нащадками, а не внуками чи правнуками).

* **Комбінатор `>`** — це класичний синтаксис CSS, який просто вказує на зв'язок між тегами в структурі сторінки.
* **Вкладеність (CSS Nesting)** — це зовсім інша фішка, коли ти пишеш стилі фізично всередині фігурних дужок іншого блоку через символ `&`.

Приклад для порівняння, щоб більше не плутати:

```css
/* 1. Селектор із комбінатором: */
.card__body > .subtitle { 
  font-size: 13px; 
}

/* 2. Справжня нативна вкладеність: */
.card__body {
  & > .subtitle { 
    font-size: 13px; 
  }
}
```
